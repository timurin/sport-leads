Добавить заказ в календарь

Выберите существующую standalone ТК. Номер и производственные данные сверяются с её снимком.

Демо-сценарии:
Ручной номер существующей группы ТК; новый номер здесь не создаётся.
Поиск только среди существующих standalone ТК группы.
Свободная подпись календаря; исходную ТК не изменяет.
Календарные зависимости показаны ниже и не меняют маршрут ТК.
Необязательный срок календаря; дата группы ТК не изменяется.
Выбранная дата уже прошла. Проверьте срок перед созданием; демонстрационное создание разрешено.
