Открытые вопросы и риски

  • Норматив: семантика одной швеи на изделие утверждена; пустые/нулевые/неприменимые строки дают unknown, ручная норма пошива в v0.1 не вводится.

  • Закупка: ручной флаг с автором/временем/причиной; PO, остатки и состав ТК не подтверждают его автоматически.
  • ТК B1: CLOSED 2026-10-05; refresh не заменяет сохранённые материалы; 13 regression tests passed. Историческое воспроизведение выше сохранено. Baseline DB/lint сбои остаются препятствием для PC-03.
  • Gate: PC-02.1 CLOSED документационно 2026-10-05; UI-A–UI-H OWNER-APPROVED, DESIGN-APPROVED = true. PC-03 не начат; старые сбои project check и непроверенное runtime/Edge QA сохранены.
