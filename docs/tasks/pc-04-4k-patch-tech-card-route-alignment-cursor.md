# PC-04.4K PATCH — Tech Card Route Visual Alignment

## Исполнитель
Cursor

## Контекст
Текущий UX уже принят по логике. Нужен только визуальный polish блока `Технологический процесс`.

Backend/runtime не менять.

## Цель
Сделать блок ровным, компактным и визуально собранным:
- единая сетка;
- одинаковые отступы;
- одинаковая высота карточек цехов;
- аккуратные стрелки;
- без случайных переносов и больших пустот.

---

## 1. Верхняя строка

Сейчас:
- select маршрута;
- badge `Требует настройки`;
- карточка прогноза

визуально не собраны.

Сделать desktop grid:

`[ Маршрут + select + status ] [ Прогноз ]`

Рекомендуемо:
- левая колонка ~ 2fr;
- правая ~ 0.8–1fr;
- одинаковая верхняя линия;
- одинаковая высота визуального блока;
- badge маршрута поставить справа от label/select, не отдельным плавающим элементом.

---

## 2. Схема маршрута — одна ровная линия

На desktop цеха должны идти в одну горизонтальную цепочку:

`ПЕЧАТЬ → РАСКРОЙ → ПОШИВ → КОНТРОЛЬ КАЧЕСТВА`

Не переносить `ПОШИВ` и `КОНТРОЛЬ КАЧЕСТВА` на вторую строку при ширине текущего экрана.

Использовать:
- responsive grid/flex;
- workshop cards с одинаковой базовой шириной;
- variant workshop может быть шире;
- остальные карточки компактнее.

Если ширины недостаточно:
- горизонтальный scroll внутри scheme area;
- не ломать цепочку на случайные строки.

---

## 3. Workshop cards

Выровнять:
- одинаковая высота для обычных цехов;
- одинаковый border-radius;
- одинаковые padding;
- заголовок цеха по одной baseline;
- операции внутри — одинаковые chip heights.

Обычные цеха:
- компактные;
- не растягивать по высоте до variant group.

Variant workshop (`РАСКРОЙ`) может быть шире, но должен совпадать по верхней линии с соседями.

---

## 4. Стрелки

Сейчас стрелки выглядят оторванными.

Сделать:
- стрелки строго по центру между workshop cards;
- одинаковая длина connector;
- не использовать отдельные стрелки в начале новой строки;
- на desktop connector всегда между двумя соседними блоками.

---

## 5. Variant Group

Сделать компактнее:
- название группы;
- badge `Предварительно` в одной строке;
- helper `Выполняется один вариант`;
- radio options в одну строку, если помещаются;
- default badge маленький;
- `Подтвердить` — компактная primary button под options либо справа.

Не растягивать блок по высоте без необходимости.

---

## 6. Forecast card

Карточку прогноза выровнять по верхнему краю с маршрутом.

До расчёта:
- компактный placeholder;
- одна кнопка `Пересчитать план`;
- без лишней высоты.

После расчёта:
- крупная дата;
- дата отгрузки;
- запас/риск.

---

## 7. Warning

Warning оставить один.

Сделать:
- компактный;
- выровнять по ширине схемы;
- одинаковые внутренние отступы;
- не увеличивать высоту блока больше текста.

---

## 8. Общие размеры

Использовать единый spacing rhythm:
- section gap;
- card gap;
- chip gap;
- label/input gap.

Не допускать:
- случайных 5–10 px различий;
- разной высоты controls;
- разной толщины border;
- разного radius у однотипных элементов.

---

## 9. Responsive

### Desktop >= 1280
- схема в одну горизонтальную линию;
- без переноса workshop cards;
- forecast справа.

### Tablet
- допускается горизонтальный scroll схемы;
- forecast переносится вниз.

### Mobile
- вертикальная схема;
- стрелки вниз;
- radio options вертикально.

---

## 10. Не менять

Не менять:
- тексты бизнес-логики;
- API;
- Scheduler;
- ONE OF semantics;
- route selection behavior;
- replan flow;
- warnings logic;
- VIS-STRESS.

Full:

## Acceptance

Готово, если:
1. вся схема на desktop идёт одной ровной линией;
2. workshop cards визуально выровнены;
3. arrows стоят по центру между блоками;
4. variant group компактный;
5. forecast выровнен с route selector;
6. нет случайных пустот и переносов;
7. tablet/mobile остаются читаемыми.
