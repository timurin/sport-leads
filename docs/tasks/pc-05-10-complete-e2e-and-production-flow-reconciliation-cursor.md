## Исходная бизнес-логика, с которой сверяемся

### Calendar
План производства:
- что;
- где;
- когда должно выполняться.

### Queue
Порядок ожидающих ТК внутри текущего участка.

### Kanban
Фактическое текущее положение ТК по участкам.

### Operator flow
`Ожидает -> Принять в работу -> В работе -> Завершить -> следующий участок`

### TechnicalCard
Хранит маршрут, данные изделия, персонализацию, статус и производственный факт.

Future Calendar assignments не должны сами перемещать Kanban.
