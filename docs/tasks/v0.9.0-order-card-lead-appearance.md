# Order card — lead appearance + communication history

**Date:** `2026-07-26`  
**Owner request:** перенести внешний вид карточки лида (`/sales/leads/[id]`) на заказ покупателя (`/sales/orders/[id]`); заказ должен отражать историю коммуникации с клиентом.

## Goal

1. Карточка заказа визуально следует компоновке Lead Card (PT-06): header, двухколоночная сетка, metrics, workspace tabs, sticky communication column.
2. История событий лида **и** заказа показывается в timeline заказа (backend уже отдаёт `LeadEvent` по `lead_id` ∪ `order_id`).
3. Правая колонка — панель коммуникаций (как у лида); контакт/клиент — из исходного лида.
4. Сохранить рабочие позиции заказа (`SalesOrderItems`) и смену статуса заказа.

## Out of scope

- Persistent messages/tasks/notes (roadmap `1.2.4`)
- Смена шаблона-контракта PT-07 в design-system docs (факт: order card переиспользует PT-06 layout; отметить в отчёте)
- Shell (`DS-SHELL-01` / `02`)
