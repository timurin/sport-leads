# Task — Spec as plan+fact report; Documents as link registry

**Date:** `2026-07-26`  
**Status:** closed (canonical docs only)  
**Roadmap:** Stage 7 architecture amend (no code)

## Owner decisions

1. **Specification** = document (not a module, not a ledger posting). Role: collect data for a **1С cost report** on production of batch of sales order №X (batch = 1 unit or 100% of the order).
2. **Spec form** = **сводный отчёт: план + факт в одной форме** (blocks fed from related platform fields). Fields are not freely editable without elevated rights.
3. Spec content blocks (logical):
   - what was sold — nomenclature (PRODUCT);
   - links — which technical cards sourced the data; which sales order;
   - materials spent — nomenclature type MATERIAL;
   - operations — production ops / volumes done / time;
   - who — operator or group responsible for the operation.
4. **Documents** (Sales → Документы) = **единый реестр ссылок** on documents that **live in their parents** (example: invoice lives on the sales order). Filtering by type (e.g. «Счета на оплату») lists all matching rows platform-wide.
5. **Do not** build a separate contour/module per document type for now. Spec persistence/UI still belongs to Stage 7 when reached; Documents index is a later cross-cut, not Stage 7 prerequisite.
