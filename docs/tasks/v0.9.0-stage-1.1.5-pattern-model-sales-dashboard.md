# Task — 1.1.5 Dashboard pattern-model sales analysis

**Roadmap:** `1.1.5.1`–`1.1.5.5`  
**Date:** `2026-07-31`

## Goal

На `/sales/dashboard` — **живая** таблица топ продаж по моделям (артикул) с фильтрами периода. Остальной дашборд может оставаться demo до отдельного persistence-этапа.

## Metrics (per model)

| Column | Rule |
|--------|------|
| Артикул / название | Snapshot `product_model_article` / `product_model_name` (group by `product_model_id` or article) |
| Заказов | `count(distinct order_id)` |
| Ед. заказано | `sum(quantity)` |
| Ед. «выпуск» | `sum(quantity)` where order status ∈ `{ready, shipped, completed}` (proxy until FG ledger) |
| Сумма | `sum(line_amount)` |
| Пошив | `sum(coalesce(assembly_variant_total_cost,0) * quantity)` |

Exclude `cancelled` orders. Only lines with model id or article.

## API
