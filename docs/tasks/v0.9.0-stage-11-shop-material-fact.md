# Task — Stage 11 shop material fact (Раскрой / Печать)

**Roadmap:** `11.3.1`, `11.5.1`–`11.5.5`, `11.6.1`–`11.6.5`  
**Date:** `2026-07-27`  
**ADR:** ADR-016 (composition plan/fact), ADR-017 (shop routing / ProductionStage); amend notes as needed in `11.3.1`

## Goal

Document and implement **material fact entry** from цеховые модули onto technical-card composition MATERIAL lines (`fact_qty`), with a **hard complete-gate** for Раскрой and Печать when any MATERIAL bound to that цех lacks `fact_qty`. Shop modules write fact onto the TC document (no second SoT). Gate enforcement stays in `9.3.4` / `9.2.2`; shop API must not bypass it.

## Dependencies

- `11.3` — shop module platform / shared contract (`11.3.1` owns material-fact + hard-gate semantics)
- `8.3` — ProductionStage (цех) catalog; stage bind on MATERIAL lines
- `9.3.4` — composition `planned_qty` / `fact_qty` / `production_stage_id` + hard gate on stage complete (`9.3.4.3` via `9.2.2`)

## Locked decisions

- Shop modules write **`fact_qty`** on TC composition **MATERIAL** lines for the **current цех** only.
- **Hard complete-gate** for Раскрой and Печать if any MATERIAL of that stage lacks `fact_qty` — enforced via `9.3.4` / `9.2.2` (shop complete must fail closed).
- `11.3` shared contract documents material fact entry + hard-gate semantics (this task file + ADR/docs note in `11.3.1`).
- `11.5` / `11.6` domain + API include `fact_qty` fields and enforce the gate on complete.
- Visuals `11.5.5` / `11.6.5`: **STOP before owner visual** — wait for owner OK; agents must not close visual checkboxes.

## Contract notes (`11.3.1`)

- Shop module ≠ second tech-card document; fact lands on existing TC composition / stage result.
- Distinct from Stage 10 client design / approval.
- MATERIAL lines carry `production_stage_id` (цех bind), `planned_qty` (hint only), `fact_qty` (цех entry).
- Hard gate: cannot complete Раскрой (`cutting`) or Печать (`print`) while any MATERIAL with that `production_stage_id` has null / unset `fact_qty`.
- Planned qty remains a hint (sizes / yield may change actual consumption); fact is SoT for consumption at the цех.
- Modules must not bypass `9.2.2` stage order or the material gate.
