# Task — `11.2.1.1` Aggregate fact roll-up contract

**Date:** `2026-07-30`  
**Roadmap:** `11.2.1.1`

## Decision

- Roll-up is a **read model** over TCs linked to a `ProductionBatch` (order = union of batches)
- SoT stays on TC (`stage_results`, MATERIAL `fact_qty`, op volumes)
- No fact writes onto ProductionOrder / ProductionBatch
- Aggregates: performers, duration sum, scrap/rework sum, output qty, material fact sums, op volume sums
- Empty batch → empty aggregates (no demo data)
