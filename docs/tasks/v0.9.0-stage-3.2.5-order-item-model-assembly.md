# Task — 3.2.5 Product model and assembly variant on order items

**Roadmap:** `3.2.5` (+ smoke `3.2.6`)  
**Moved from:** Stage `6.1.13` / `6.4.1` (`2026-07-22`)  
**Why Stage 3:** commercial selection and snapshots belong to **Заказ покупателя** order lines; Stage 6 owns catalog masters; PRODUCT whitelist config stays on nomenclature card (`6.1.11`).

## Scope

After nomenclature on the order line:
1. Pick `product_model` ∈ PRODUCT available-models whitelist
2. Autofill model article + size_type (+ name)
3. Show **assembly variant** field only after model is selected (hidden without model; options = active variants of that model)
4. Pick `assembly_variant` of that model — **required** when the model has ≥1 active variant (Stage 7 Spec / Stage 9 TC need the assembly-operation snapshot; not soft-optional). If the model has zero active variants, variant stays optional until variants are configured (ADR-014 §5)
5. Persist nullable FKs + immutable snapshots (incl. assembly operation-line child table)

Price / VAT are separate commercial fields and are out of `3.2.5.4`.
