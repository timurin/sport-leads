# Task — 3.3.1 Order-level discount

**Roadmap:** `3.3.1.1`–`3.3.1.5`  
**Date:** `2026-07-31`  
**ADR:** ADR-003 amend

## Goal

Процентная скидка на весь заказ поверх уже посчитанных `line_amount` строк.

## Contract

| Field | Type | Rules |
|-------|------|--------|
| `discount_percent` | `Numeric(5,2)` nullable | 0–100; `null`/`0` = no order discount |
| `discount_amount` | `Numeric(14,2)` not null | **computed** only: `round(items_subtotal × percent / 100, 2)` |
| `amount` | existing | `items_subtotal − discount_amount` |
| `items_subtotal` | API read-only | `sum(line_amount)`; not a DB column |

Order:
1. Line discounts (`SalesOrderItem.discount_percent`) → `line_amount`
2. Order discount on sum of `line_amount`
3. VAT / currency / invoices stay in `3.3.2` / `3.3.3` (out of scope)

## UI

- Order card «Основные сведения» / metrics: editable `%` скидки заказа; show subtotal, discount amount, total
- Line discounts unchanged

## Out of scope

- Absolute order discount amount as manual input
- Multi-currency
- Tax-inclusive recalculation (`3.3.2`)

## Status

**Closed** `2026-07-31` (`3.3.1.1`–`3.3.1.5`). Evidence: Alembic `c0d1e2f3a456`; API `PATCH /orders/{id}/discount`; UI metrics; tests `test_order_discount_3_3_1.py` + FE order-discount/metrics; project-structure + erp-check synced.
