## Formulas (canonical)

Money: `Decimal` / round half-up to **2** dp (FE helpers currently banker's `Math.round` to kopecks — align to Decimal in service).

### A. НДС сверху (цена **без** налога) — `price_includes_vat = false`

Дано: сумма без НДС (`net` = `line_amount`).

| | Formula |
|--|---------|
| Сумма НДС | `net × (rate / 100)` |
| Итого с НДС | `net × (1 + rate / 100)` |

Пример `rate=22`, `net=10_000`: НДС=`2_200`, с НДС=`12_200`.

### B. НДС в сумме / цене (выделение) — `price_includes_vat = true`

Дано: сумма **с** НДС (`gross` = `line_amount`).

| | Formula |
|--|---------|
| Сумма НДС | `gross × [rate / (100 + rate)]` |
| Без НДС | `gross − НДС` |

Пример `rate=22`, `gross=12_200`: НДС=`2_200`, без НДС=`10_000`.

### C. Без НДС (`rate = 0`)

`vat_amount = 0`; `net = gross = base`.

Helpers (FE): `calculateExclusiveVatAmount` / `calculateAmountWithVat` / `calculateInclusiveVatAmount` / `calculateAmountWithoutVat` / `calculateLineVatAmount` / `calculateLineGrossAmount` — `frontend/lib/vat-rates.ts` + `vat-rates.test.mjs`.

## Contract (SoT)

| Rule | Detail |
|------|--------|
| Price mode | **Per line** field `price_includes_vat`; UI toolbar `BadgePercent` toggles and **applies to all rows** (`true` = в сумме). Default `true` |
| Line `vat_amount` | Computed only; formula **B** if inclusive, **A** if exclusive |
| Line contribution | Inclusive: `line_amount`; exclusive: `line_amount + vat` (pre–order-discount). API `line_total` |
| Taxable base (line) | After **line** discount (`line_amount`); then scaled by order discount factor `amount / items_subtotal` |
| Order `items_subtotal` | Σ line contributions **with VAT** |
| Order `vat_amount` | `sum(line.vat_amount)` after order-discount scale |
| Order `amount` | Post–order-discount **gross** total (`3.3.1`) |
| Order `amount_net` (API read) | `amount − vat_amount` |
| Missing / 0% rate | `vat_amount = 0` |
| Manual VAT | Forbidden |

### Calc order (extends `3.3.1`)

1. Line: price → line discount → `line_amount` (entered base: gross if inclusive, net if exclusive)  
2. Line VAT (scale=1) → line contribution with VAT → `items_subtotal`  
3. Order: order % → `discount_amount` / `amount`  
4. VAT rescale: taxable = `line_amount × (amount / items_subtotal)` → mode formula → store `vat_amount`  
5. Order `vat_amount` = Σ line VAT; `amount_net` = `amount − vat_amount`

## Document transfer rule (price-related docs)

При создании / копировании коммерческих документов из позиций заказа (КП / счёт / УПД / печатные формы `3.3.3` / Stage 18 и любые будущие price docs) **обязательно переносить snapshot**:

| Field | Why |
|-------|-----|
| `price_includes_vat` | Режим «в сумме / сверху» — без него нельзя пересчитать/показать НДС |
| `vat_rate_id` / `vat_rate_percent` | Ставка |
| `vat_amount` | Зафиксированная сумма НДС на момент документа |
| `unit_price`, `quantity`, `discount_*`, `line_amount` | Денежная база строки |
| `line_total` (или эквивалент gross) | Итог строки с НДС |

Запрещено: терять `price_includes_vat` и заново угадывать режим только по UI defaults. Источник правды режима — snapshot строки-источника.

## UI

- Toolbar icon `BadgePercent`: toggle **НДС в сумме / сверху** и **применить ко всем строкам** (`price_includes_vat`)
- Active (primary) = все строки «в сумме»; inactive = сверху (или смешанный до клика)
- Колонки: сумма / % НДС / сумма НДС / всего (с учётом режима)
- Metrics / карточка: НДС и сумма без НДС из API
- Prefer persisted `vat_amount` after save; draft grid считает client-side до refresh

## Out of scope

- Full invoice / UPD / print implementation (`3.3.3` / Stage 18) — только transfer rule  
- 1C tax exchange  
- Multi-currency
