Открыть коммерческие price-документы заказа: **валюта (MVP)**, **КП (quotation)** и **счёт на оплату (invoice)**. Печать потребляет реестр Stage **18** (без параллельного store шаблонов). Перенос НДС-режима — по правилу `3.3.2`.

## Contract

### Currency (MVP)

| Rule | Detail |
|------|--------|
| Code | ISO 4217 string on `SalesOrder.currency_code`, default **`RUB`** |
| Scope | Same code copied onto quotation / invoice header at create |
| FX / multi-rate | **Out of MVP** — one currency per order document set; no conversion engine |
| Money fields | Remain `Numeric` in document currency (no dual base/currency amounts yet) |
| UI | Show code on order metrics / doc headers; picker deferred if only RUB seeded |

### Quotation (КП) and Invoice (счёт)

| Rule | Detail |
|------|--------|
| Parent | Always `sales_order_id` (live on the order — ADR-004) |
| Create | From order (and invoice optionally from quotation) via service snapshot |
| Lines | Immutable commercial snapshot at create (MVP: create + read) |
| VAT transfer | **Mandatory** copy per line: `price_includes_vat`, `vat_rate_id` / `vat_rate_percent`, `vat_amount`, `unit_price`, `quantity`, discounts, `line_amount`, line gross (`3.3.2` transfer rule) |
| Header totals | Snapshot order `discount_*`, `vat_amount`, `amount` / `amount_net` |
| Numbering | `КП-{order_id}-{seq}`, `СЧ-{order_id}-{seq}` |
| Status | `draft` / `issued` / `cancelled` |
| Waybill / UPD / ТН | **Out of `3.3.3` MVP** — keep planned tree nodes |

### Documents UI / registry

| Rule | Detail |
|------|--------|
| Order card tree | Live КП/счёт nodes + create actions |
| Global «Документы» sales list | ADR-004 later — not required to close `3.3.3` |

### Print handoff (Stage 18)

| Type | Payload source |
|------|----------------|
| `sales_quotation` | `SalesQuotation` + items snapshot |
| `sales_invoice` | `SalesInvoice` + items snapshot |
| `sales_order` | existing order read (optional cover sheet) |

No template bytes stored in sales module. Full template CRUD = `18.3.*`.
