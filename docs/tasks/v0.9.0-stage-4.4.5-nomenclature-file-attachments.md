# Task — 4.4.5 Nomenclature non-image attachments

**Roadmap:** `4.4.5.1`–`4.4.5.3`  
**Date:** `2026-07-31`

## Goal

Allow PDF / Office / ZIP / text attachments on the nomenclature card without a second storage table.

## Contract

| Rule | Detail |
|------|--------|
| Storage | Same `nomenclature_media` + `storage/nomenclature-media` |
| Images | jpeg/png/webp/(svg); may be `is_primary`; carousel UI |
| Files | pdf, doc/docx, xls/xlsx, zip, txt, csv; never primary |
| Size | ≤ 10 MB (unchanged) |
| Content | existing `GET …/media/{id}/content` with filename |

## Out of scope

- Virus scan / preview for Office
- Product-model / tech-card attachments (separate later)
- Changing import `photo_paths` to pack binaries
