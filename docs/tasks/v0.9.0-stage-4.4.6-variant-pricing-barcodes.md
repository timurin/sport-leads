# Task — 4.4.6 Variant pricing / barcodes / external code

**Roadmap:** `4.4.6.1`–`4.4.6.4`  
**Date:** `2026-07-31`  
**ADR:** ADR-010 amend

## Goal

Commercial attributes on `NomenclatureVariant` without opening the 1C exchange engine.

## Contract

| Field | Type | Rules |
|-------|------|--------|
| `price` | `Numeric(14,2)` nullable | ≥ 0; `null` = inherit `Nomenclature.base_price` |
| `barcode` | `String(64)` nullable | unique when set |
| `external_code` | `String(100)` nullable | opaque key for future `16.2.1`; no sync jobs here |

## UI

- Card «Варианты» list: article, name, price, barcode, external_code, active toggle
- Sales order item: when variant selected, default `unit_price` = variant.price ?? nomenclature.basePrice (user may still override)

## Out of scope

- Price types / multi-currency price lists
- Live 1C UNF exchange (`16.2.1`)
- Generating barcodes
