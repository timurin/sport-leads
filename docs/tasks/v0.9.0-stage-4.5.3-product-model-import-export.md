# Task — 4.5.3 Product models import / export

**Roadmap:** `4.5.3.1`–`4.5.3.3`  
**ADR:** ADR-020 contour A (catalog file I/O)  
**Date:** `2026-07-30`

## Goal

Reuse shared CSV/XLSX parse library for the product-models catalog (second adapter after nomenclature).

## Scope

- Columns: `id`, `article`, `name`, `size_type`, `size_grid_name`, `product_type_name`, `description`, `patterns_path`, `constructor_name`, `patterns_created_on`, `default_routing_code`, `status`, timestamps
- Upsert by `id` then case-insensitive `article`
- Toolbar Import/Export on `/settings/catalogs/product-models`
- Template download with sample rows

## Out of scope

- Assembly variants / routing whitelist rows / media binary pack
- Universal job shell (`16.3`)

## Evidence

- Backend: `product_model_file_columns.py`, `product_model_import.py`, `product_model_export.py`, API on `/product-models`
- Frontend: `product-models-workspace.tsx`, `product-model-import-drawer.tsx`
- Tests: `test_product_model_import_export_4_5_3.py`, `product-model-import-export-4-5-3.test.mjs`
