# Task — 4.5.4 Sewing operations import / export

**Roadmap:** `4.5.4.1`–`4.5.4.4`  
**ADR:** ADR-020 contour A (catalog file I/O)  
**Date:** `2026-08-24`

## Goal

Reuse shared CSV/XLSX parse library for the sewing-operations catalog (third adapter after nomenclature and product-models).

## Scope

- Host `/settings/catalogs/sewing_operations`
- Columns: `id`, `name`, `cost`, `quantity_per_item`, `duration_seconds`, `folder_path`, `sort_order`, `work_center_codes`, timestamps
- Upsert by `id` then case-insensitive `name`
- `folder_path` with ` / `; create missing folders on commit
- `work_center_codes` via `|`; sewing-stage + active only; do not create work centers
- Toolbar Import/Export; template download with sample rows
- Dry-run default; all-or-nothing commit

## Out of scope

- Sewing-operation templates (`6.3.12`)
- Creating `WorkCenter` rows
- Universal job shell (`16.3`)

## Evidence

- Backend: `sewing_operation_file_columns.py`, `sewing_operation_import.py`, `sewing_operation_export.py`, API on `/sewing-operations`
- Frontend: `sewing-operations-workspace.tsx`, `sewing-operation-import-drawer.tsx`
- Tests: `test_sewing_operation_import_export_4_5_4.py`, `sewing-operation-import-export-4-5-4.test.mjs`
