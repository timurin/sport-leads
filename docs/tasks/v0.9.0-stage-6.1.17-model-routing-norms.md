## Goal

Each product model owns an ordered whitelist of existing `ShopRoutingTemplate` presets (UX like assembly variants — link/unlink only) plus per-link **operation material norms** (`norm_qty_per_item` + unit) bound to `production_stage_id` / `tech_operation_id`. Norms are a **plan hint for 1 unit** (e.g. 0.7 linear meters per t-shirt), not a hard BOM×order-qty. Routing master CRUD stays at `/settings/catalogs/routings`. When the whitelist is non-empty, `default_routing_template_id` must ∈ whitelist.

## Locked decisions

- **Whitelist, not clone:** `ProductModelRoutingLink` attaches existing `ShopRoutingTemplate` rows; do **not** duplicate routing CRUD on the model card.
- **Norms = plan hint:** `ProductModelOperationNorm` stores `norm_qty_per_item` + unit on model+routing+stage/op; feeds TC planned consumption later — **not** fact, **not** hard BOM×qty.
- **Default ∈ whitelist:** when whitelist non-empty, `ProductModel.default_routing_template_id` must belong to the whitelist (or be cleared).

## Domain entities sketch

| Entity | Role |
|--------|------|
| `ProductModelRoutingLink` | Ordered whitelist row: `product_model_id` ↔ `shop_routing_template_id`; unique (model, routing); sort_order; active filter on list |
| `ProductModelOperationNorm` | Plan hint on a whitelist link: `production_stage_id` and/or `tech_operation_id`, `norm_qty_per_item` (Decimal), `unit`; unique per model+routing+stage/op binding |
| `ProductModel.default_routing_template_id` | Existing nullable FK; when whitelist non-empty must ∈ link set |

Rules:

- Whitelist empty → default may stay null (or existing FK until first links are added — enforce on write when links present).
- Removing a link that is the current default clears or rejects until default reassigned.
- Norm qty > 0 (or ≥ 0 if zero means “no plan hint” — pick one in schemas and keep Decimal-safe).
- Stage 8 catalog remains the only SoT for routing stage sequences; model never owns stage lines.

## API sketch

| Method | Path | Notes |
|--------|------|-------|
| GET | `/product-models/{id}/routings` | Whitelist + nested norms; active templates only (or mark inactive) |
| PUT / POST | `/product-models/{id}/routings` | Replace or add links (ordered); reject unknown / foreign routing ids |
| PATCH / DELETE | `/product-models/{id}/routings/{link_id}` | Reorder, remove; default integrity |
| PUT | `/product-models/{id}/routings/{link_id}/norms` | Replace norms for one link |
| PATCH | `/product-models/{id}` (existing) | Setting `default_routing_template_id` validates ∈ whitelist when whitelist non-empty |

Validation:

- Foreign / inactive routing attach → reject.
- Default not in whitelist (when whitelist non-empty) → reject.
- Norm Decimal + unit required; stage/op must exist and match routing context where applicable.
