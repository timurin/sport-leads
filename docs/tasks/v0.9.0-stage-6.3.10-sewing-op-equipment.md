# Task — 6.3.10 Sewing operation ↔ sewing-shop equipment

**Roadmap:** `6.3.10.1`–`6.3.10.5`  
**Date:** `2026-07-31`  
**ADR:** ADR-014 / ADR-017 amend; domain `sewing-operations-domain.md`

## Goal

Привязать оборудование (`WorkCenter`) к справочнику **операций пошива** (`SewingOperation`). В выборку попадают только станки с цехом **Пошив** (`ProductionStage.code = sewing`).

## Contract

| Rule | Detail |
|------|--------|
| Link | M:N `sewing_operation_work_centers` (`sewing_operation_id`, `work_center_id`, unique pair) |
| Candidates | Active `WorkCenter` whose `production_stage.code == "sewing"` |
| Reject | WorkCenter without sewing stage → 422 |
| Cardinality | Operation: 0..N equipment; equipment: 0..N operations |
| Snapshots | **Do not** copy `work_center_id` onto `AssemblyOperationLine` / order / TC in this package |

## Boundary vs `11.1.2`

| Contour | Role |
|---------|------|
| `6.3.10` catalog link | Which sewing-shop machines are compatible with a sewing-op catalog row |
| Routing / TC WorkCenter | Planned/fact equipment on stage execution (`ShopRoutingStageLine` → `TechnicalCardStageResult`) |

## UI

- Create/edit sewing operation: multi-select оборудования (filtered to цех Пошив)
- Work-centers catalog unchanged except filter reuse if needed

## Out of scope

- Link to `TechOperation` (Stage 8)
- Capacity / calendars
- Auto-assign WC on TC from sewing-op catalog
