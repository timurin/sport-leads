# Task — 8.1.4 TechOperation required materials

**Roadmap:** `8.1.4.1`–`8.1.4.3`  
**Date:** `2026-07-28`  
**ADR:** ADR-017 amend (`2026-07-28`)

## Goal

Extend the shop `TechOperation` catalog with optional default required-material rows that describe consumption per one operation `volume_unit`.

## Example

For `Сублимационная печать`:

- paper: `1 m` per `1 linear_meter`
- ink: `10 g` per `1 linear_meter`

These rows are defaults for Stage `9.3.5` technical-card composition prefill, not warehouse postings and not a second material catalog.

## Microtasks

- [ ] `8.1.4.1` — Domain child rows on TechOperation: MATERIAL nomenclature + qty per `volume_unit`
- [ ] `8.1.4.2` — DB/API/settings UI for create, edit, delete, list
- [ ] `8.1.4.3` — Regression tests + docs checkpoint

## Rules

- Parent remains `TechOperation`
- Child row references only MATERIAL nomenclature
- Quantity stores required amount for one operation `volume_unit`
- No coupling to `SewingOperation`
- No direct stock/fact semantics in this stage

## Out of scope

- Warehouse movement
- Fact consumption
- Model-specific overrides on the TechOperation card itself

## Acceptance

- [ ] Settings UI under `/settings/catalogs/tech-operations` edits required-material rows
- [ ] API round-trips child rows persistently
- [ ] Rows can be consumed by Stage `9.3.5` technical-card prefill
