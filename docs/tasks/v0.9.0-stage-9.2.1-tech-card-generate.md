# Task — 9.2.1 Create technical cards from sales order

**Roadmap:** `9.2.1.1`–`9.2.1.4`  
**Date:** `2026-07-26`  
**ADR:** `docs/architecture/decisions/ADR-016-technical-card-domain.md`

## Goal

Create one technical card per eligible order line; sync unit lines when quantity changes; expose generate / preview / cancel-draft API.

## Microtasks

- [x] `9.2.1.1` — Service: create card per manufacturable line; prefill nomenclature / model / assembly snapshots (Spec/routing/op-volume empty until 7/8/`8.1.3`)
- [x] `9.2.1.2` — Service: sync unit line count with order line quantity
- [x] `9.2.1.3` — API: preview, generate, sync-unit-lines, cancel draft (+ get/list-by-order)
- [x] `9.2.1.4` — Regression tests

## API

| Method | Path |
|--------|------|
| POST | `/orders/{id}/technical-cards/preview` |
| POST | `/orders/{id}/technical-cards/generate` |
| GET | `/orders/{id}/technical-cards` |
| GET | `/technical-cards/{id}` |
| POST | `/technical-cards/{id}/sync-unit-lines` |
| POST | `/technical-cards/{id}/cancel` |

Eligible MVP: linked nomenclature `PRODUCT`, whole positive qty. Cancelled draft can be revived by generate (stable `number` / `card_seq`).
