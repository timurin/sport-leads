# Task — 9.2.2 Technical card state machine and routing execution

**Roadmap:** `9.2.2`

**Status:** closed (code + tests; no UI)

## Goal

Strict stage gates on technical cards using snapshot `stage_results` from Stage 8 routing. Card status transitions: draft → in_progress → completed; cancel remains draft-only.

## API

- `POST /technical-cards/{id}/start` — draft → in_progress; first pending stage → in_progress
- `POST /technical-cards/{id}/stages/{stage_order}/start` — start stage (previous must be completed)
- `POST /technical-cards/{id}/stages/{stage_order}/complete` — complete with performer/scrap/rework/notes
- `POST /technical-cards/{id}/stages/{stage_order}/rollback` — controlled rollback of last open completed stage
