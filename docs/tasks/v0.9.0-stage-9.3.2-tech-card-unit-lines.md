# Task — 9.3.2 Unit lines (sizes and personalization)

**Roadmap:** `9.3.2.1`–`9.3.2.4`  
**Date:** `2026-07-26`  
**ADR:** ADR-016 §2

## Goal

Editable per-piece unit lines inside one technical card; defaults from order-item snapshots; bulk/import hooks.

## Microtasks

- [x] `9.3.2.1` — Field set: `unit_index`, `size`, `personalization`, `print_number`, `color`, `notes` + validation
- [x] `9.3.2.2` — Defaults from order line (`size_range` / `personalization` / `color`); reset-defaults endpoint
- [x] `9.3.2.3` — API: list / patch / put replace / bulk / import / reset-defaults (count via existing sync-unit-lines)
- [x] `9.3.2.4` — Regression tests

## API

| Method | Path |
|--------|------|
| GET | `/technical-cards/{id}/unit-lines` |
| PATCH | `/technical-cards/{id}/unit-lines/{line_id}` |
| PUT | `/technical-cards/{id}/unit-lines` |
| POST | `/technical-cards/{id}/unit-lines/bulk` |
| POST | `/technical-cards/{id}/unit-lines/import` |
| POST | `/technical-cards/{id}/unit-lines/reset-defaults` |

Replace requires exactly N rows (`1..N` = order qty). Cancelled/completed cards are read-only.
