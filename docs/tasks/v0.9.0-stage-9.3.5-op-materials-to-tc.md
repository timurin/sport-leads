# Task — 9.3.5 TechOperation required materials to technical card composition

**Roadmap:** `9.3.5.1`–`9.3.5.3`  
**Date:** `2026-07-28`  
**ADR:** ADR-016 / ADR-017 amendments (`2026-07-28`)

## Goal

When the routing snapshot on a technical card references a `TechOperation` with required-material rows, prefill technical-card MATERIAL composition lines and compute the planned quantity from operation material consumption and the model routing norm.

## Formula

`planned_qty = required_material_qty × norm_qty_per_item × order_qty`

Where:

- `required_material_qty` comes from the TechOperation child BOM (`8.1.4`)
- `norm_qty_per_item` comes from `ProductModelOperationNorm` (`6.1.17`)
- `order_qty` comes from the technical card order line

## Matching rules

- Prefer norm matched by `tech_operation_id`
- Fallback to stage-level norm for the same `production_stage_id`
- If no norm matches, do not fabricate `planned_qty`
- MATERIAL row still remains visible for manager correction
