**Remove:** nothing required

### Threat note

LAN mode binds services on all interfaces. Anyone on the same L2/L3 segment can reach FE/BE. Auth cookies remain `Secure=false` in local dev. Treat as trusted-LAN only; not a substitute for VPS/TLS production.
