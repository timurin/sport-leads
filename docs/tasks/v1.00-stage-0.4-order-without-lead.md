## 0.4.1 Contract (closed)

### Current state (evidence)

| Fact | Location |

### Decision

1. **`lead_id` nullable**  
   - Migration: `ALTER … DROP NOT NULL` on `sales_orders.lead_id`.  
   - Keep `uq_sales_orders_lead_id` (PostgreSQL/SQLite: multiple NULLs allowed; one order per non-null lead).  
   - Convert-from-lead **unchanged**: still sets `lead_id`, completes lead, emits events.

2. **Create API (new)** — `POST /orders`  
   Body (`SalesOrderCreate`):
   - **Required:** `client_id`, `organization_id`, `responsible_id`, `title`  
   - **Optional:** `number` (freeform), `description`, `product_category`, `sport`, `quantity`, `amount`, `desired_date`, `source`, `currency_code` (default `RUB`)  
   - **Forbidden on this path:** `lead_id` (always `NULL` for without-lead create)  
   - Response: `SalesOrderRead` (`lead_id: int | null`)

3. **Numbering**  
   - Omit / null / blank `number` → auto after flush: `SO-{UTC year}-{id:06d}` (same as convert).  
   - Provided `number`: trim, length 1…50, unique → else **409**; reject whitespace-only.  
   - Do not invent a second auto pattern.

4. **UI entry**  
   - `/sales/orders` primary action «Создать заказ» → real create drawer (not demo).  
   - Fields: client, organization, responsible, title, optional number, optional commercial basics.  
   - On success → navigate to `/sales/orders/{id}`.  
   - Lead convert dialog remains the convert-only path.

5. **Technical cards**  
   - **No orphan TC** on order create.  
   - After order exists + manufacturable PRODUCT line → existing generate API (ADR-016).  
   - Freeform order number is for order header / later TC number template only.

6. **Downstream null-safety (must ship with implement)**  
   - `GET /orders/{id}/source-lead` → 404 when `lead_id is None`.  
   - `GET /orders/{id}/history` → filter by `order_id` only when `lead_id is None` (do not `lead_id == NULL` match).  
   - FE order card: source-lead link/label optional when null.  
   - Tasks panel via lead stays empty when no lead (already CRM-only).

7. **Stage 20 / field-links**  
   - Stage `20.4` owns further order-card UX; **create without lead owned by `0.4`**.  
   - `order-card-field-links.md`: Source lead → **optional** FK (update in `0.4.3` checkpoint).  
   - Mermaid: `SalesOrder -.-> Lead` (optional).

8. **ADR**  
   - Amend **ADR-001** (do not fork a parallel create ADR).  
   - ADR-002 org remains nullable on model; **without-lead create requires** `organization_id`.

9. **Out of scope for 0.4**  
   - Attaching a lead to an existing without-lead order.  
   - Creating Organization as a standalone admin form (find/create-by-company-name on client create is allowed).  
   - UNF Excel import (`16.2.1`) — only enables future prefetch via freeform number.  
   - Changing convert payload / lead completion rules.

### UX amend (`2026-08-05`, owner request during `0.4.2`)

- Inline **create Client** in order drawer (`POST /clients`).
- `Client.organization_id` nullable FK (Alembic `j3k4l5m6n789`).
- Auto org for **existing** client: `Client.organization_id` → last order org → Organization by name (`default_organization_id` on list/detail).
- **New client:** checkbox **«Создать организацию?»** (default off). Checked → show name/ИНН/ОГРН and create/link org. Unchecked → client **without** organization (`company_name` alone does not create org).
- Order `organization_id` optional on `POST /orders`.
