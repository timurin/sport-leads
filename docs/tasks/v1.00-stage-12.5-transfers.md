## Domain (`12.5.1.1`)

- One document, two warehouses. Type `transfer`. Number `STK-*` (existing sequence).
- Header: source = existing `warehouse_id`; dest = `destination_warehouse_id` (required for transfer, NULL on other types). Dest ≠ source. Both must be active.
- Lines: unique nomenclature; `quantity > 0`. Draft lines live in `stock_transfer_lines`, not in the ledger.
- Post writes **two** ledger rows per line: signed `−qty` on source, `+qty` on dest. Empty lines cannot post. Posted = immutable.
- Instant post — no in-transit warehouse, no second document (not a paired issue+receipt).
- No `technical_card_id` / `sales_order_id` required.
- MVP does not block shortage below zero on the source (same as `issue`).
- Host: `/warehouse/movements`. No Documents module. No bins/lots. No reserves here.
- List warehouse filter matches source **or** dest. Slim list: no nested transfer lines.
