## Domain (`13.1.1.1`)

- One supplier directory under Закупки. Routes: list `/purchases/suppliers`, card `/purchases/suppliers/[id]`.
- `name` required (≤255). `code` optional, unique when set (≤50). `inn` 10/12 digits if set; `kpp` 9 if set. Contacts/address/notes optional. Soft-deactivate via `is_active` (no hard delete if prices exist — or cascade prices on delete; prefer block delete when prices exist).
- Supplier price: `supplier_id` + `nomenclature_id` + `unit_price` (> 0) + `currency` default `RUB`. Unique pair. Optional `comment` ≤255.
- List: search by name/code/inn; filter active; slim DTO (no price array).
- Detail: card fields + prices table (nomenclature name embed + price); add/edit/remove price.
- Hub `/purchases`: real empty/count from API after FE ships — never invent demo suppliers.
- Money via Decimal/Numeric. No VAT on supplier price in this slice (purchase VAT later with PO/receipt).

## Out of scope (`13.1.1.1`)

SQLAlchemy / Alembic / API / UI in the **contract** iteration. Purchase orders `13.1.2`. Receipts/returns `13.2.1`. Demand/min stock `13.2.2`. Bank accounts. Rating. 1C. DS-SHELL visual edits. Merging suppliers with `Client`.
