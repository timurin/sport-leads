## Domain (`13.1.2.1`)

- One document type: заказ поставщику. No separate «заявка» table — `draft` is the internal request.
- Number auto `PO-######` (unique). `supplier_id` required; supplier must exist (prefer active on create).
- Statuses MVP: `draft` → `ordered` (confirm) → `cancelled` (cancel from draft or ordered). No `partial` / `closed` until receipts.
- Lines: unique nomenclature per PO; `quantity > 0`; `unit_price > 0`; currency header `RUB`. Default price from matching `SupplierPrice` when client omits price.
- Edit lines / supplier / expected_date / warehouse only while `draft`. Ordered: notes only (optional) or immutable header except cancel.
- Confirm requires ≥1 line. Confirm and cancel do **not** touch ledger.
- Optional `warehouse_id` = expected receipt warehouse (active warehouse if set).
- Hosts: `/purchases/orders`, `/purchases/orders/[id]`. Slim list DTO (no nested lines). Hub: live empty/count — never demo PO-S-* rows.
- Money via Decimal/Numeric. No VAT in this slice.
