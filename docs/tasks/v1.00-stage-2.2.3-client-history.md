# Task — 2.2.3 Client lead and order history

**Roadmap:** `2.2.3.1`–`2.2.3.5` (`SL-ROADMAP-v1.00`)  
**Date:** `2026-08-23`  
**Contract code:** `SL-CLIENT-HISTORY-v1`

## Host

Embed on existing client card `2.2.2` / `/sales/clients/[clientId]` (`DS-PT-05`).  
Do **not** put history arrays on `GET /clients` list DTO (`SL-LIST-PAGE-RULES-v1`).

## Sources

| Kind | How a row belongs to the client |
|------|----------------------------------|
| `order` | `SalesOrder.client_id` |
| `lead` | `SalesOrder.lead_id` of those orders **or** `Lead.converted_order_id` in those orders **or** same normalized email/phone as `Client` (`find_duplicate_leads` / duplicate helpers) |

Deduplicate leads by `id`. Clients created without a lead (`0.4`) may have only orders.

## API

`GET /clients/{client_id}/history`

| Query | Default | Notes |
|-------|---------|--------|
| `kind` | `all` | `all` \| `lead` \| `order` |
| `limit` | `50` | max `200` |
| `offset` | `0` | |

Sort: `occurred_at` desc, then `kind`, then `id`.  
404 if client missing. Empty: `{ items: [], total: 0 }`.

Item (slim):

| Field | Lead | Order |
|-------|------|-------|
| `kind` | `lead` | `order` |
| `id` | lead id | order id |
| `occurred_at` | `Lead.created_at` | `SalesOrder.created_at` |
| `title` | contact / company / need | number + title |
| `status` | lead status | order status |
| `amount` | null | order amount |
| `sport` | lead sport | order sport |
| `source` | lead source | null |

`GET /clients/{id}` keeps `recent_orders` (last 20). History panel is the full mixed list.

## UI
