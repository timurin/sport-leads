## Host

`/sales/clients` list workspace (`DS-PT-02`).  
Tree + list filter (not PT-04 warehouse dock).  
Do **not** put folder trees on `GET /clients` list DTO (`SL-LIST-PAGE-RULES-v1`).  
List row may embed `folder_id` + `folder_name` only.

## Model

`ClientFolder` — same skeleton as sewing-op / product-model folders (no template field).

| Field | Rule |
|-------|------|
| `parent_id` | self-FK `RESTRICT`; `NULL` = root |
| `name` | stripped; unique among siblings (case-insensitive) |
| `sort_order` | `≥ 0`; sibling order |

`Client.folder_id` nullable FK → `client_folders` `ON DELETE RESTRICT`.  
`NULL` = unfiled bucket («Без папки»).

Delete folder only when it has **no child folders** and **no clients**.  
Moves are cycle-safe (self / descendant parent rejected).

## API

Prefix `/client-folders`:

| Method | Path |
|--------|------|
| `GET` | `/client-folders` |
| `POST` | `/client-folders` `{ name, parent_id?, sort_order? }` |
| `GET` | `/client-folders/{id}` |
| `PATCH` | `/client-folders/{id}` `{ name?, parent_id?, sort_order? }` |
| `POST` | `/client-folders/{id}/move-sibling` `{ direction: up\|down }` |
| `DELETE` | `/client-folders/{id}` → 204 |

Errors: 404 missing; 409 duplicate sibling name; 422 cycle / non-empty delete / empty patch.

`GET /clients` + optional `folder_id` (exact folder). Descendant filter is FE (`isCatalogFolderDescendant`).  
List DTO: `folder_id`, `folder_name`.  
`PATCH /clients/{id}` `{ folder_id: int \| null }` assigns / unfiles.  
`POST /clients` may set `folder_id`.

Card loads: `GET /clients` + `GET /client-folders` (fixed pair).

## UI

- Selecting a folder filters the existing clients table by that folder ∪ descendants.
- Row shows folder name; move client via folder select (no demo substitution).
