## Segments

Child table `client_segments` (`client_id` CASCADE).

| Field | Rule |
|-------|------|
| `name` | 1–64 chars, trim; unique per client case-insensitive |
| max per client | 32 |

Free-form tags (not a global catalog). Blank / duplicate-in-payload ignored after normalize.

`PUT /clients/{id}/segments` body `{ "tags": ["VIP", "школа"] }` — replace-all.

## Duplicates

Warning only — **never** block create/update (same spirit as lead `duplicate-candidates`).

Match **OR** of provided non-empty criteria:

| Field | Normalize | Match |
|-------|-----------|--------|
| `name` | trim + casefold | `company_name` **or** `contact_name` of another client |
| `phone` | digits; `8XXXXXXXXXX` → `7…` (lead helper) | `Client.phone` |
| `inn` | digits only | `Client.inn` |

At least one criterion required → else 422.

`GET /clients/duplicate-candidates?name=&phone=&inn=&exclude_client_id=` **before** `/{client_id}`.

Returns slim rows: `id`, `company_name`, `contact_name`, `phone`, `inn`, `matched_on[]`.
