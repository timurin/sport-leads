## SoT

Persistent `Organization` (`backend/app/models/sales.py`) is the only SoT for **our** legal entities used on `SalesOrder.organization_id`.

| Not SoT | Why |
|---------|-----|
| `organizationRecords` / `organizationsDefinition` | Demo `EntityWorkspace` path — **drop** |
| `Client` requisites (`2.3.1`) | Client INN/KPP/OGRN are **not** synced to Organization |
| Employee / department pages | `2.4.2` |
| Bank accounts / warehouses / history tabs | Not on the model; out of MVP |

When Stage 14 / warehouse catalogs need org banking or warehouses, they extend this entity — they do not revive the demo inspector tabs.

## API

Existing: `GET /organizations?active_only=true` (default **true** so order pickers stay on active orgs).

Settings list uses `active_only=false` to show archived.

Gaps to add (`2.4.1.2`):

| Method | Path | Notes |
|--------|------|-------|
| `GET` | `/organizations/{id}` | 404 if missing |
| `POST` | `/organizations` | 201; name required |
| `PATCH` | `/organizations/{id}` | `exclude_unset`; empty patch → 422 |

No DELETE. Archive via `is_active=false`. Duplicate `tax_id` → 409. Unique `tax_id` still allows many NULL.

Do **not** change lead conversion / client-create org find-or-create.

## UI

- Drop `organizationRecords`. Empty API list = empty state, not demo.
- List columns: name, legal_form, INN (`tax_id`), director, status. Row → card.
- Create drawer: name + INN + legal form (rest on card).
- Card: all writable fields above; no pay/bank/employees/warehouses/history tabs.
- No silent demo substitution on load error.
