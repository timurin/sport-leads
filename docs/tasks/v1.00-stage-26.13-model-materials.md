## Decisions (locked `2026-08-29`)

| Topic | Decision |
|-------|----------|
| Fabric shop | Separate tab; usable in print **and** cutting |
| Fabric → stage | One «Цех» field per row: print **or** cutting; both shops → **two rows**, different plan qty |
| Detailing applicability | Product type(s) («Вид изделия»), **multi**; not folder |
| Material name | Nomenclature `MATERIAL` pick only |
| Model → TC sync | Prefill on model **bind/change** only; then manual; no auto-rewrite on BOM save |
| Packaging | One tab → `packaging` (no separate WTO tab) |
| Hardware type/color | Characteristic options (not free text) |
