## Contract (`SL-STANDALONE-TC-v1`)

### Dual contours

| Contour | Entry | Rule |
|---------|--------|------|
| **A** | `SalesOrder` → `SalesOrderItem` → PRODUCT | Generate TC from selected nomenclature + item qty → unit lines (ADR-016). Unchanged cardinality: ≤1 TC per eligible item. |
| **B** | Manual create without required `SalesOrder` | Internal production (scrap, gifts, etc.). TC links to `technical_card_order_groups`. |

Both share shop / QR / FG execution on the TechnicalCard. Spec / ProductionOrder without SalesOrder is **parked** (`28.5`).

### Order group (contour B)

| Field | Rule |
|-------|------|
| `order_number` | Free text; **unique among standalone groups** (may coincide with a real `SalesOrder.number` — no FK) |
| `tech_cards_planned_count` | Manager-entered plan (≥ 1); **no** auto-create of N cards |
| `desired_date` | Manual ship date (static snapshot for B) |

### Planned TC count (both contours)

- On **A**: field on `SalesOrder` (`tech_cards_planned_count`).
- On **B**: field on the order group.
- Meaning: how many tech cards the manager expects for that order/group.
- **Soft progress only** («3 of 5»): create/generate is **not** blocked when actual ≠ planned.

### Numbering

| Layer | Format |
|-------|--------|
| Stored `TechnicalCard.number` | `{orderNo}-{card_seq}` |
| Display / print / UI | `{orderNo}-{card_seq}/{N}` |

`N` = **live** planned count from SalesOrder or group. Changing planned count updates display everywhere without rewriting stored `number`.

Example: order `1310`, planned `5`, first card → store `1310-1`, show `1310-1/5`.

### Contour B create form (MVP)

Required:

1. Nomenclature (`PRODUCT`)
2. Order number (group key)
3. Planned tech-card count
4. Ship date (`desired_date`)
5. Quantity ≥ 1 → create **qty** unit lines immediately

### FK rules (when implementing `28.2.1`)

- `sales_order_id` / `sales_order_item_id` → **nullable**
- Both null **or** both set (no half-link)
- UNIQUE on `sales_order_item_id` only when not null
- Contour B: `order_group_id` set; SalesOrder FKs null
