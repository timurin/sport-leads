## Domain (`7.1.1`)

### Parent + entities

One `Specification` per `ProductionBatch`. Versions + product / material / operation lines on the version. Number `{batchNumber}-SPEC`. TC must already be in the batch.

### Lifecycle

`draft` (refreshable, one per header) → `approved` (immutable; all linked TCs terminal) → later draft `v{n+1}` then approve supersedes previous. `cancelled` for discarded drafts.

**Not a start gate:** batch / TC do not wait for Spec.

### Materials

TC `line_kind=material` only. Plan = `planned_qty`, fact = `fact_qty`. No accessory type. No substitute table (TC has none). No stock-ledger second SoT.

### Copy/read

Assembly + routing/sewing volumes from **TC snapshots** (order-item already snapshotted). Performers / time from stage results; sewing fact qty from completed ledger. Live model edit does not rewrite `approved` versions.

### Documents

Do **not** build Documents module. Spec lives on the batch; interim list `/production/specifications` in `7.2.2`.

## Out of scope (`7.1.1`)

SQLAlchemy / Alembic / API / UI. 1C adapter. Costing Stage 15. DS-SHELL visual edits. New RBAC codes.
